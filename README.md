# مستشارك - المساعد القانوني المصري

> بوابتك الأولية لفهم المواقف القانونية في مصر، تنظيم المعلومات، وتحديد الخطوات والوثائق المطلوبة بدقة وسهولة.

---

## 📱 عن المشروع
**مستشارك** هو تطبيق ويب تطوري (PWA) مصمم لمساعدة المستخدمين في مصر على فهم إطاراتهم القانونية الأولية في مختلف المجالات (العمل، الإيجارات، الأحوال الشخصية، المدني، التجاري، الجنائي، الإداري، والمرور). يتيح التطبيق مسارين للاستخدام:
1. **الأسئلة الموجّهة:** أسئلة متسلسلة مبسطة تساعد في تصنيف الموقف وتحديد النقص في المستندات.
2. **الكتابة الحرّة:** إمكانية سرد تفاصيل المشكلة بكلمات المستخدم ليقوم النظام بتحليلها مبدئياً.

---

## 🛠️ التقنيات المستخدمة
* **HTML5 / CSS3 / JavaScript (Vanilla):** بناء خفيف، سريع، وبدون مكتبات خارجية معقدة.
* **Responsive Design & Dark/Light Mode:** دعم كامل للتصميم المتجاوب مع الهواتف الذكية وتفضيلات الألوان (فاتح/داكن).
* **Progressive Web App (PWA):** إمكانية تثبيت التطبيق على الشاشة الرئيسية للهواتف والعمل دون اتصال مباشر بعد التحميل الأول.

---

## 📂 هيكل المشروع
* `index.html`: الملف الرئيسي الشامل للواجهات، التصميم، ومنطق التحليل والخدمات.
* `manifest.webmanifest`: إعدادات وتكوينات الويب المتاحة للتثبيت على الهواتف.
* `sw.js`: ملف Service Worker لدعم التشغيل Offline.
* `icons/`: أيقونات التطبيق بأحجام مختلفة.

---

## 🚀 التشغيل المحلي والاختبار
1. قم بتحميل أو استنساخ المستودع (Clone).
2. ارفع الملفات إلى خادم يدعم **HTTPS** (مثل GitHub Pages أو Cloudflare Pages)، أو اختبرها محلياً عبر `localhost`.
3. افتح الرابط من متصفح الهاتف واستمتع بالتجربة.

---

## ⚠️ إخلاء مسؤولية قانونية
المعلومات والتحليلات المعروضة عبر تطبيق "مستشارك" هي لأغراض الإرشاد الأولي والتنظيم فقط، **وليست استشارة قانونية رسمية** أو بديلة عن الاستعانة بمحامٍ مرخص أو الجهات القضائية الرسمية.
